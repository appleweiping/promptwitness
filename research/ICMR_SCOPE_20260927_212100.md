## 问题与三项待验证内容（同一科学问题，不新增成功端点）

输入为参考图像与自然语言修改描述，输出为完整候选图像库的排名。
固定图像检索器；搜索的是把参考图像描述和修改描述组合为目标查询的 prompt。
如果使用CIR训练标签选择prompt，整套方法是冻结backbone的监督prompt搜索，
不能因未训练视觉encoder就称training-free/zero-shot CIR。
研究瓶颈是每次 prompt 修改需要大量查询改写、文本编码和检索评估。

- C1：在完整预声明文本、相同允许父记录、匹配拟合数据与计算后，显式
  typed parent→child edit×query 表示作为归纳偏置是否具有经验边际价值，能否在
  相同风险判定质量下降低真实审计成本。不是文本缺少这些信息或首个结构先验。
- C2：采用既有有限总体推断工具的具体 paired Delta/R 审计设计。读取本候选
  输出前冻结分层、计划与层内SRSWOR顺序，实际观测而非预测产生证书。
  candidate-outcome-free 不等于所有outcomes均未用：允许父correctness是已知父结果。
  仅换成Delta/R或精确区间不构成新风险控制定理；不同estimand不豁免效率对照。
- C3（此前此文件C2）：在匹配全角色资源预算下，这种评估方式是否帮助既有
  优化器得到更好的未见查询检索结果。C1效率改善本身不证明C3。

不是提出新的 CIR 任务，不声称首个 LLM 查询改写、首个候选反馈或新的视觉编码器。
初期查新记录见 `../idea-stage/ICMR_NOVELTY_CHECK.md`；同家族provisional意见
不证明方法新颖性，真实增益与科学准入仍待实验。

## 实际多媒体链路与可复用边界

参考图像 → 固定视觉编码器 → 参考视觉向量；候选图像 → 同一编码器 → 固定索引。
参考图像的固定、无目标信息 caption 与用户修改描述 → 两个原主模型之一 →
目标描述 → 同一检索器的文本编码 → 固定图像/文本融合 → 全库排名 → 真值评分。

Qwen3.5-9B 与 OLMo-3-7B-Instruct 保留原模型/精度/执行约束。两者均接收相同
caption+修改描述，不能把文本 OLMo 描述成视觉模型，也不能给 Qwen 额外图像输入
后把差异解释为优化器收益。视觉链路确实处理图像；caption 是固定中间表示，
不是用文字数据伪装多模态。比较原始修改文本、无 LLM 融合，验证 caption 和 LLM
是否必要。现有 `check_contract` 对图像 content_parts 的 UNSUPPORTED 保持不变；
此方案不把它改成未经验证的多模态行为保证。

主 backbone 拟用冻结 CLIP ViT-L/14；权重版本、预处理、融合权重和 captioner
仍须在训练侧确定并冻结。UniIR/SEARLE/CoRR 用于强检索系统对照和适配鲁棒性，
不是直接套用其公布数字作我们的结果。不重训视觉编码器，不先增加 agent 工具规划。

## 数据、指标与估计量

主数据候选为 CIRR 和 FashionIQ（dress / shirt / toptee）。只先获取官方训练侧
数据；官方 validation 在本研究中作为 sealed final，不用于挑 prompt、backbone
或融合权重。训练侧按 reference-image/近重复组分 fit/search/selection，不按单行
随机拆分。共享无标注候选图像库允许，但目标关联、subset 信息只给 scorer；
不得给 proposer。审计公开原始 train/val 的图像与重复重叠，不能声称天然独立。
若 grouping 导致某阶段数据不足，记录设计问题并修订，不能用 final 补齐。

- CIRR：完整库 R@1/5/10/50、subset R@1/2/3；从全库排名删除参考图像后再评分。
- FashionIQ：各类别 R@10/50、类别等权 macro 与查询等权 micro；沿本次核对的
  evaluator 约定保留参考图像，不把 CIRR 的排除规则悄悄推广过去。
- 现有二元 certifier 的主端点：CIRR query hit@5；FashionIQ query hit@10。
  每查询一个已标注目标，此时 hit 等于单查询 recall。Delta 和 R 的分母是冻结
  查询数，不是候选数或仅 old-correct 数。FashionIQ 的证明只涉及 query-micro
  hit@10，不覆盖类别 macro、R@50、subset、AP、语义满足或未来用户安全。
- survivor 须补全原选择器所需实际排名和完整真实分数；不能用预测补 native vector。
  CIRCO 多真值 mAP 不是二元分数，不接进当前 hypergeometric certifier。

CIRCO 可作为以后单独的 frozen transfer：只用未参与开发的 validation；其 test
是外部服务器。当前不访问测试标注、不上传结果，不把可选扩展当作必须前置条件。
M-BEIR 是相关的统一检索 benchmark，但不能混用其 union-pool 与原 CIRR/FashionIQ
候选库得到的数字。本方向先做原 benchmark，M-BEIR 属于明确分开的后续范围。

## 紧凑确认矩阵与对照

候选设计：2 datasets × 2 原生成模型 × 5 原 seeds（11,23,37,53,71）×
6 原 evaluator/configurations = 120 主 runs；每 dataset/model 24 对，共 96
机制 pairs；第三模型冻结 prompt transfer 拟 24。这是 venue-driven 新设计，不是
通过缩矩阵挽救旧成本门禁。未获取数据/背骨/全角色报价之前不称冻结或可负担。
所有失败、INCONCLUSIVE 和提前停止保留分母；default ARIS MAX_ROUNDS=4 不变。

三组比较：

1. 同一 GEPA/MIPRO 的严格 full/native-minibatch、强 generic evaluator、text-only
   与结构 evaluator；必须共享必要 selector 适配与实际成本边界。
2. 检索系统参考：原始图文融合与无改写；选可合法复现的强 CIR 方法，保持其
   实际原输入/检索流程，不能把弱 fusion 当 SOTA。代码/权重/数据适配尚未通过。
3. 结构消融及失败分析：仅文本、去 caption、去图像/修改指令、类别和修改类型。
   最后两种是诊断，不是偷偷改变主模型或正式系统。

沿用旧成功目标作为待检验目标，不放宽：对 full 30%成本下降、强 generic 15%、
结构对 text-only 10%、clear-eligible 保留95%；主效果两点宏平均改善和调整后
正下界，并逐 dataset 非劣。统计方案需对不同 k、类别与选择后的结果审查。
旧 certifier alpha/epsilon/r_max 不改；不能声称 campaign-wide 5% 错误保证。

## 运行顺序和准入

1. CPU M0：独立排名/评分核，单目标严格检查，CIRR reference/subset 与 FashionIQ
   macro/micro 差异；authored fixtures 接现有 AuditPlan/journal/gate。不是模型实验。
2. 数据/权限 M1：数据和各权重许可、source pin、训练分组、sealed final、scorer
   原程序一致性、全库规模与 tie 行为；新上下文审查与按文档实际执行。
3. 真实基线 M2：owned 环境一次真实图像编码与索引、原查询与固定 caption、两
   生成模型实际工作量。费用含下载/CPU/图像预处理/caption/cache/index/search/
   proposer/bootstrap/reflection/selection/final/失败/cold/idle/whole allocation。
   原生成 transport 资格不等于视觉 backend 或新数据资格。
4. Pilot/消融 M3：真实 M1 fit、在线随机单元与原优化器；证明有效再确认冻结。
5. M4：准入后一次新矩阵、统计、负结果、8页正文+最多2额外参考页英文稿。
   ICMR 不允许附录/补充材料，关键条件与局限必须在正文。

实际费用总上限继续跨版本累计，800k calls / 1000 allocatedGPUh / 2B input /
200M output / paid0；不清零已发生1170calls/2136046input/195222output/
3.8074371029887377allocatedGPUh，不推断 historical unknown 为0。
当前新方向全部真实费用 UNMEASURED_NOT_ZERO；按 consumed+1.20*forecast 准入，
不预支 early rejection 收益。没有新增自定小额度、付费 API、云租赁或定时器。
