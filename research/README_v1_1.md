## Implemented research core

`promptwitness.incremental` provides input-only traceable structured/text feature
vectors, missingness, two CPU logistic transition heads, optional cost prediction,
finite-suite fixed stratified sampling, exact-tail count bounds, Delta/R decisions,
durable audit plans/candidate slots/query accounting, complete cache identities,
physical resource accounting and fail-closed native score-vector boundaries.
Install `promptwitness[research]` for SciPy/scikit-learn methods. Ordinary package
import and unrelated zero-dependency commands do not import those extras.

The real research predictor is **UNFITTED**. Synthetic unit-test fits are not
training-side scientific evidence. The native bridges exercise actual pinned
evaluation interfaces; they are **not** a completed early-rejection engine or a
claim of optimization savings. DSPy must use `failure_score=NaN, max_errors=1`;
its default exception-to-zero conversion cannot enter a certificate.

## Offline recorded-table CLI

`promptwitness delta plan --help`, `delta run --help` and `delta report --help`
describe the finite recorded-table mechanism. Freeze the plan before opening
candidate outcomes. The journal binds the full outcome file digest, retains
failures and candidate slots, and refuses silent recovery with different data.
Use fresh system randomness for conditional finite-table inference. Deterministic
hash-permutation seeded fixtures are mechanical tests only, not SRSWOR.

Supported suite size is 1..4096; at most eight homogeneous-reference strata and
32 nonrecycled candidate slots. The allowance is 1/61440 per direction/stratum/
look/slot, totaling at most 0.05 per run, not per entire campaign or future users.
Unknown contracts/execution assumptions produce UNSUPPORTED, not formal labels.

--cov=promptwitness.incremental --cov-report=json:core-coverage.json
--cov-fail-under=90`, then `python reproduce/check_g1_branch_coverage.py
core-coverage.json`. The second command separately requires 90% branch coverage;
