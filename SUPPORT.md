# Support

- Use [Discussions](https://github.com/appleweiping/promptwitness/discussions) for usage questions and design ideas.
- Use [Issues](https://github.com/appleweiping/promptwitness/issues) for reproducible defects and accepted feature work.
- Use [private vulnerability reporting](https://github.com/appleweiping/promptwitness/security/advisories/new) for security concerns.

Support is best-effort. Public reports must use sanitized prompts and must not expose credentials, production system
instructions, confidential tool schemas, or model outputs.
