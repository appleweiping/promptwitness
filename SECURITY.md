# Security policy

## Supported versions

Security fixes are provided for the latest release on the `main` branch.

## Reporting

Please do not open a public issue for a suspected vulnerability or include live
credentials in a reproduction. Use GitHub's private vulnerability reporting for
this repository. Include affected versions, impact, a minimal sanitized
reproduction, and any proposed mitigation.

The project owner will acknowledge a report as soon as practical, investigate,
and coordinate disclosure after a fix is available. The literal-secret check is
a convenience heuristic and is not a security boundary or substitute for a
dedicated scanner.
