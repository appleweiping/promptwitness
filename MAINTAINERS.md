# Maintainers

PromptWitness is currently maintained by [@appleweiping](https://github.com/appleweiping).

Maintainers review prompt compatibility, conversion loss, policy semantics, SARIF correctness, documentation, and
release evidence. Contributions are accepted through pull requests; a maintainer remains accountable for every merge.

Security reports must use [private vulnerability reporting](https://github.com/appleweiping/promptwitness/security/advisories/new).
