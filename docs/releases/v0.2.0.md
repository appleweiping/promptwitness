# PromptWitness 0.2.0

Released 2026-08-31.

PromptWitness 0.2 adds loss-aware provider conversion, deterministic structural alignment,
versioned policy files, and SARIF output while keeping the strict native prompt schema at version 1.

## Highlights

- Explicit OpenAI, Anthropic, and LangChain adapters convert documented prompt subsets without
  network calls. Represented values are preserved, ignored field names are reported as warnings,
  and non-text or otherwise unrepresentable semantics fail instead of being silently dropped.
- Smart message alignment uses deterministic dynamic programming and memory-efficient backtracking.
  Positional alignment remains available when sequence positions are the intended contract.
- Strict policy schema version 1 configures validation, alignment, metadata comparison, context
  lines, and per-change severity overrides. Overrides flow consistently into report counts,
  compatibility decisions, SARIF levels, and CLI gates.
- SARIF 2.1.0 output presents the same typed validation/diff facts as JSON and Markdown. Stable rule
  IDs, RFC 6901 locations, and deterministic fingerprints support repeatable code-scanning results.
- Provider examples, policy documentation, and a deterministic synthetic alignment benchmark are
  included.

## Compatibility and migration

The native prompt and report schemas remain version 1. Existing strict parsing, validation,
positional comparison, JSON/Markdown/HTML reporting, and CLI flows remain available. Provider
payloads are not accepted implicitly by the native parser: use an explicit adapter or CLI input
format. For long-lived CI, choose the provider format explicitly instead of depending on
auto-detection precedence.

Policy files are optional. Because a policy can change severities and the CLI gate outcome, policy
changes should be reviewed and version-controlled alongside prompt changes.

## Verification

The release candidate passed 121 tests with 94.87% branch coverage. The suite covers strict native
parsing, provider loss/error paths, deterministic smart alignment and ties, policy validation and
severity propagation, RFC 6901 paths, SARIF fingerprints, output escaping, and CLI gates. The
benchmark is a reproducible workload description, not a portable timing guarantee.

## Known boundaries

- Provider adapters intentionally cover text-oriented subsets. OpenAI non-function tools and
  unsupported content blocks, Anthropic image/document/tool-use/tool-result blocks, and arbitrary
  LangChain runnable graphs are rejected or reported according to the documented adapter contract.
- Smart alignment evaluates a quadratic message-pair grid. Direction rows are rolled, but a
  one-byte-per-cell backtracking matrix remains; message length also affects similarity cost.
- Standard JSON parsing materializes the complete document. Callers accepting untrusted uploads
  should impose their own file-size limit.
- PromptWitness checks structural compatibility and review hazards. It does not score prompt
  quality, call an LLM, prove safety, or replace a dedicated secret scanner.
